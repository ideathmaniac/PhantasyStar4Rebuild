Звезда Фантазии IV — версия для Linux и Steam Deck
===================================================

Запуск
------
1. Распакуйте папку куда угодно (например, ~/Games/PS4).
2. Положите рядом с программой ROM (русский перевод, fix v7) под именем
   ps4_rus.bin — или просто запустите программу, и она спросит, где ROM.
3. Запустите ./PS4 (или: ./PS4 путь/к/rom.bin).

Нужны библиотеки SDL2 и OpenGL — они есть почти везде (SteamOS, Ubuntu 22.04
и новее, Fedora, Arch, Mint). Если SDL2 нет: sudo apt install libsdl2-2.0-0
(или sudo pacman -S sdl2, sudo dnf install SDL2).

Steam Deck
----------
1. Перейдите в режим рабочего стола, распакуйте папку, положите ROM рядом.
2. Правой кнопкой по файлу PS4 → «Add to Steam» (Добавить в Steam).
3. Вернитесь в игровой режим: игра появится в библиотеке в разделе
   «Не из Steam». Управление встроенным геймпадом работает сразу:
   крестовина/стик — движение, X — A, B — B, A — C, Start — Start,
   View (⧉) — меню. Сенсорный экран работает в меню как мышь.

Сохранения, настройки и снимки экрана лежат рядом с программой — так же, как
в версии для Windows; файлы сохранений между версиями совместимы.

Эта сборка содержит только интерпретатор процессора (без кода игры) — она
работает с любым подходящим ROM и не включает ничего из самой игры.
